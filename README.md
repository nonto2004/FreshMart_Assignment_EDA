# FreshMart Data Profiling and Cleaning Analysis

## Project Overview

This project analyses FreshMart supermarket transaction, store, and
stockout data to investigate why customer footfall increased while
revenue remained relatively flat.

The analysis focuses on:
- Customer basket value
- Number of items per transaction
- Loyalty vs non-loyalty customers
- Competitor presence
- Stockout events
- Monthly and regional trends

## Key Findings

- Average basket value declined from ZAR 299.82 in January to
  ZAR 248.56 in December.
- Loyalty customers had higher average basket values than
  non-loyalty customers.
- Stores with nearby discount competitors generally had lower
  basket values.
- Stockout events showed little connection with the overall
  decline in basket size.
